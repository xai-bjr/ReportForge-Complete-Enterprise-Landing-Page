FAQ

Questions? We've got answers.

No. All 5 integrations use free official APIs. Google gives you 10,000 YouTube quota units per day — enough for hundreds of reports. Instagram, TikTok, and GA4 all have free developer tiers. The only paid option is if you want to use your own OpenAI key for the AI-written analysis (optional).
Absolutely. Every report template is a plain HTML file (Jinja2 syntax) sitting in the templates/ folder. Open it in any text editor, change the layout, add your own sections, insert custom CSS. The next report you generate will use your edited version.
Yes. ReportForge stores everything locally in a SQLite database on your machine. Nothing is uploaded to our servers (we don't have any). API tokens are encrypted at rest. If you unplug the internet, ReportForge still works using cached data.
ReportForge handles hundreds of clients fine. Batch mode processes them in parallel on your CPU cores. The only real constraint is API rate limits — for large numbers we recommend running the batch overnight via the scheduler.
The packaged .exe is Windows-only. The source code runs fine on macOS and Linux with PySide6 + WeasyPrint installed — but the packaged build for those platforms is on our Q3 2026 roadmap. Contact us if you need it sooner.
